# JETSKI Website

A simple static website scaffold for your new JETSKI project.
#ffffff#a5b5d1#000000
## Files

- `index.html` — main website page
- `styles.css` — responsive layout and theme styling
- `script.js` — mobile menu toggle interaction

## Run locally

Open `index.html` in your browser, or use a static file server if needed.

## AI assistant

The website includes a built-in AI chat section. To use it:

1. Open the `AI` section in the page.
2. Paste your OpenAI API key into the API key field.
3. Save the key and use the ai to create your website.

> The API key is stored only in your browser local storage.

## Customize

Update the text, colors, images, and sections to match your brand or project.
